# Poor Man's Training on MCUs: A Memory-Efficient Quantized Back-Propagation-Free Approach

* [11/07/2024] Our [paper](https://arxiv.org/abs/2411.05873) is released on arXiv.

# Overview

In this work, we enable full-model on-device training under extremely constrained memory (e.g., microcontrollers with 1024 KB or 256 KB SRAM). 

Our work contains three parts to achieve efficient on-device training: 
1. Training Real Quantized Models via Quantized Zeroth-Order Optimization
2. Memory-Efficient Adaptive Weight/Node Perturbation
3. Further Dimension Reduction via Sparse Training
